# Project instructions

- Communicate with the user in Slovak. Use English for code and technical identifiers.
- Read `docs/project-status.md` and the relevant specification before implementation.
- After completing a task and appropriate verification, automatically commit the changes you made for that task.
- Use a concise, descriptive commit title. Do not include unrelated user changes in your commits.
- Leave `git push` to the user.
- Keep `docs/project-status.md` current after significant changes. Report verification accurately; distinguish code checks, simulator tests and physical-device tests.
